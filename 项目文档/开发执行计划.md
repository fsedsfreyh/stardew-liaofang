## 三、关键技术方案

### 3.1 像素素材生成（代码实时绘制）

不依赖外部图片文件，所有精灵在游戏启动时由 GDScript 绘制生成，存入 ImageTexture。

```gdscript
# 方案：用 Image 绘制像素图
var img = Image.create(16, 16, false, Image.FORMAT_RGBA8)
img.set_pixel(x, y, Color("#ff6b8a"))
var tex = ImageTexture.create_from_image(img)
```

**优点**：无需外部素材、色彩可控、可动态换装
**缺点**：启动时生成开销
**优化**：首次生成后缓存为 .res 文件

### 3.2 时间系统

```
DayTime 结构：
- 游戏最小单位 = 1 Tick（现实 ≈ 0.83秒）
- 1 小时 = 60 Tick（现实 ≈ 50秒）
- 1 天 = 1440 Tick（现实 ≈ 20分钟）
- 1 季 = 28 天
- 1 年 = 4 季
```

用 `Engine.time_scale` 控制时间流速，支持暂停。

### 3.3 NPC 作息调度

每个 NPC 有一个 `ScheduleEntry[]` 数组：
```gdscript
[{hour: 6, minute: 0, position: Vector2(320, 480), animation: "walk"},
 {hour: 8, minute: 0, position: Vector2(640, 320), animation: "idle"}]
```

游戏时间每 Tick 驱动 NPC 沿路径点移动。A* 寻路用 Godot 内置 NavigationAgent2D。

### 3.4 地图架构

- 主地图用 **TileMapLayer**（Godot 4.x 新特性）
- 每个区域是一个独立场景（Scene）
- 场景切换用 `change_scene_to_file()`
- 区域连接处用 Area2D 触发

### 3.5 好感度与剧情触发

```
AffectionSystem (Autoload 全局)：
- 每个 NPC 好感度 0-10❤（每❤=100点）
- 送礼/对话/完成任务 增加
- 到达关键❤数 解锁剧情节点
- 廖芳特殊规则：任何礼物都加好感（其他 NPC 有喜恶）
```
