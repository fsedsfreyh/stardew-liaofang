## 🎮 游戏简介

《星露乡物语》是一款以中国乡村为背景的农场经营生活模拟游戏。继承祖父的农场，种植作物、饲养动物、探索矿洞、结交朋友、邂逅爱情……

### ✨ 当前已实现

- 🌾 **农场经营** — 80×65 大型农场，耕地/播种/浇水/收获
- 🌿 **四季系统** — 昼夜交替、四季轮转、动态天气
- 🏘️ **小镇探索** — Pelican Town 风格小镇，中央喷泉、商店、诊所
- 🌲 **森林冒险** — Cindersap Forest 风格森林，大池塘、巫师塔
- ⛏️ **矿洞探险** — 30层矿洞，矿石采集
- 💕 **好感系统** — NPC 好感度，送礼互动，特殊NPC「廖芳」
- 📦 **背包系统** — 物品管理、快捷栏
- 🎣 **钓鱼小游戏** — 迷你钓鱼系统
- 🛒 **商店系统** — NPC Bill 的商店，买卖物品
- 📜 **任务成就** — 新手引导任务链，成就解锁
- 🏠 **房屋升级** — 升级农舍
- 💌 **邮箱系统** — 每日邮件

### 🚧 开发中

- 更多 NPC 及恋爱剧情
- 节日活动
- 烹饪/工匠系统
- 宠物系统
- 音效与BGM
